# Pi Pet

A desktop pet for Omarchy that watches **pi** (the coding agent) and talks to you in its own voice.

This is a pi-only fork of [agent-pet](https://github.com/chthollyphile/agent-pet) / [dsh-pet](https://github.com/PC2005-cloud/dsh-pet).
Everything for Claude Code, Codex, rate-limit usage and step summarising was removed: one agent, one event source, one model.

## What it does

- **Pet behaviour**: idling, random actions, walking, click reactions, physics-based dragging and throwing.
- **Live work status**: six states (thinking, working, reading results, waiting on you, done, error) driven by a small pi extension, plus the project name, the running tool and its command, and the context-window usage.
- **Murmurs**: every few minutes she says one short line, generated by your own `pi` with your own model. Streaming, with a thinking phase you can watch.
- **Attention alerts**: a desktop notification when pi needs you, finishes, or fails — only when the terminal is not focused, and carrying nothing but the agent name and state.

## Requirements

- Omarchy 4
- `qt6-imageformats` (WebP decoding for Qt); run `omarchy-restart-shell` after installing it
- `pi` on `PATH`
- `notify-send` for desktop notifications

No `jq`, `socat`, `python` or any rate-limit collector any more.

## Install

```bash
omarchy plugin add <this repo> --enable
~/.config/omarchy/plugins/<id>/chmod.sh                 # 挂载上 chmod 不生效时用这个补可执行位
~/.config/omarchy/plugins/<id>/bin/agent-pet-install     # 符号链接宿主侧扩展，重启 pi 后生效
```

`bin/agent-pet-install --uninstall` 只删自己那一条链接。

## Configuration

Defaults live in `assets/config.json`; put overrides in `~/.config/agent-pet/config.jsonc` (comments allowed, hot-reloads on save).

Merging is **deep**: objects merge key by key, arrays are replaced whole, and `null` deletes a key so it falls back to the built-in default. You only need to write what you change:

```jsonc
{
  "pet": { "size": 260 },
  "bubble": { "detail": true },
  "murmur": { "enabled": true, "model": "anthropic/claude-haiku-4-5" }
}
```

### Murmurs

```jsonc
"murmur": {
  "enabled": false,              // 关掉就完全不调用模型
  "model": "",                   // 必填 provider/model；空 = 功能关闭
  "provider": "",                // 同名模型消歧，一般不用填
  "thinking": "low",             // off|minimal|low|medium|high|xhigh|max
  "session": "agent-pet",        // 持久会话 ID；空 = 每次无状态
  "extensions": [],              // 额外扩展路径，只有列出的会加载
  "tools": ["pet_state"],        // 工具白名单；空数组 = 零工具
  "intervalSec": 600,
  "stream": true,                // false = 退回 --mode text 一次性输出
  "typewriterCps": 30,           // 0 = 原速吐字
  "showThinking": true,          // 灰字显示她"正在想"的那几行
  "firstTokenTimeoutSec": 15,
  "timeoutSec": 120
}
```

`model` 为空时不会启动任何进程——不会退回到 pi 的默认模型，也不会偷偷花你的钱。

## How the two pi processes relate

```
你的 pi (TUI)
  └─ ext/agent-pet-pi.ts        ← 装在 ~/.pi/agent/extensions，只写 socket，单向
        │  unix socket  $XDG_RUNTIME_DIR/agent-pet/events.sock
        ▼
    omarchy-shell （本插件 Service.qml）
        │  带 id 的请求才回一行（子进程问状态）
        ▲
  └─ 宠物自己的 pi (headless)   ← 由 bin/agent-pet-pi 启动，严格隔离
        └─ ext/pet.ts            ← 唯一注册的工具 pet_state
```

宿主 pi 的扩展和宠物 pi 的扩展**永远不会互相加载**：前者靠目录自动发现（子进程用 `--no-extensions` 关掉），后者靠 `-e` 白名单（你的 TUI 不会去加载它）。

## The pet's own pi is strictly sandboxed

`bin/agent-pet-pi` 是唯一允许 spawn 子 pi 的地方，flag 写死在脚本里：

- `--no-extensions` + 只 `-e` 白名单里的扩展；`--no-mcp --no-skills --no-prompt-templates --no-context-files --no-approve`
- 工作目录固定在 `~/.local/state/agent-pet/pi-cwd`（空目录），从根上找不到项目 `.pi`
- 工具面由 `murmur.tools` 全量替换，空数组 = `-nt`（零工具）
- 剥掉继承来的 `PI_CODING_AGENT_DIR` / `PI_MODEL` 等变量，强制 `PI_TELEMETRY=0 PI_SKIP_VERSION_CHECK=1 PI_OFFLINE=1`；`PI_OFFLINE` 只关版本检查与目录刷新，不影响模型请求
- 提示词走 stdin，系统提示词走 `assets/persona.*.md`，都不进进程参数

限制的是**模型能调用什么**，不是扩展的权限：`-e` 列出的扩展在 pi 进程里以你的用户身份运行。想加扩展就往 `murmur.extensions` 里写路径，自己心里有数即可。

## IPC

```bash
omarchy-shell agent-pet state     # JSON: 会话、状态、上下文、说话状态
omarchy-shell agent-pet say "Hello"
omarchy-shell agent-pet play 写代码
omarchy-shell agent-pet murmur    # 立刻碎碎念一句
omarchy-shell agent-pet context   # 上下文占用
omarchy-shell agent-pet toggle    # 隐藏 / 显示
omarchy-shell agent-pet reload    # 重载配置
omarchy-shell agent-pet forget    # 清空她的持久会话（记忆）
```

## Runtime files

| Path | Description |
|---|---|
| `Service.qml` | 配置、会话状态、说话、通知、IPC |
| `Pi.qml` | spawn 子 pi + 流式解析 + 相位机 |
| `EventServer.qml` | unix socket，两个生产者共用 |
| `ext/agent-pet-pi.ts` | 宿主侧状态上报（装在 pi 的扩展目录） |
| `ext/pet.ts` | 子进程侧 `pet_state` 工具 |
| `bin/agent-pet-pi` | 唯一 spawn 点，隔离 flag 写死 |
| `~/.local/state/agent-pet/pi-sessions/` | 她的持久会话（`agent-pet forget` 清空） |
